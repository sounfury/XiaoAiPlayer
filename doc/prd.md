# PRD：小爱音箱控制 Windows Spotify 播放助手

## 1. 项目背景

我有一个小爱音箱 Play 增强版，希望利用它 24 小时待命的语音能力，控制 Windows 电脑上的 Spotify 播放。

目前 Spotify 播放设备固定为 Windows 电脑，因此不希望依赖手机操作，也不希望引入 Home Assistant 等重量级自动化平台。

目标：

通过语音指令，让小爱音箱控制电脑 Spotify，实现日常音乐播放。

---

# 2. 设备环境

## 硬件

- 小爱音箱 Play 增强版
- Windows 11 电脑

## 软件

- Spotify Desktop（Windows版）
- 家庭局域网环境

## 运行要求

- 控制服务运行在 Windows 电脑本地
- 电脑开机后自动运行
- 无需额外服务器
- 长时间后台运行
- 低资源占用

---

# 3. 功能需求

## 3.1 基础播放控制

支持语音控制：

- 播放
- 暂停
- 继续播放
- 下一首
- 上一首

---

## 3.2 指定歌曲播放

示例：

“小爱同学，播放周杰伦的歌”

验收：

- 能根据语音内容搜索对应歌曲
- 自动在 Spotify 中播放匹配结果

---

## 3.3 随机播放我的音乐

示例：

“小爱同学，随机播放我的歌单”

验收：

- 获取用户 Spotify 歌单列表
- 随机选择一个歌单
- 随机播放该歌单中的歌曲

---

## 3.4 随机播放指定歌单

示例：

“小爱同学，随机播放我的华语经典歌单”

（示例名称，实际根据 Spotify 歌单名称）

验收：

- 根据用户指定歌单名称匹配 Spotify 歌单
- 随机播放该歌单中的歌曲

---

## 3.5 播放指定歌单

示例：

“小爱同学，播放我的工作歌单”

验收：

- 根据歌单名称找到对应 Spotify Playlist
- 开始播放

---

## 3.6 播放状态查询

示例：

“小爱同学，现在播放什么歌”

验收：

返回：

- 当前歌曲名称
- 歌手
- 播放状态

---

# 4. 非功能需求

## 稳定性

- Windows 开机自动启动
- 服务异常自动恢复
- 有基础日志方便排查问题

## 性能

- 长驻后台运行
- 低 CPU 占用
- 低内存占用

## 使用体验

- 用户无需打开手机
- 用户无需操作电脑
- 语音完成主要操作

---

# 5. MVP 验收标准

第一阶段完成以下闭环：

1. 小爱收到语音指令
2. 指令传递到 Windows 服务
3. Windows 服务控制 Spotify
4. Spotify 正常播放音乐

必须支持：

- 播放指定歌曲
- 暂停/继续
- 下一首
- 随机播放我的歌单
- 随机播放指定歌单

---

# 6. 后续扩展方向

未来可支持：

- 更自然的语义理解
- 根据场景推荐音乐
- 与其他 Windows 自动化能力结合
- 接入 AI 助手能力


| 功能 | 你可以怎么说 | 需要补什么 |
|---|---|---|
| **复合家居控制** | “空调26度低风，灯调暗一点” | 多动作解析、设备能力映射 |
| **跨模块场景** | “进入工作模式”：开软件、调灯、播放专注歌单 | 把 Windows、Spotify、家居动作编排起来 |
| **相对调节** | “空调再高两度”“灯比现在暗一点” | 先读取当前状态，再计算目标值 |
| **连续指令** | “打开卧室空调”→“再把风速调低” | 短期上下文，记住上次控制的设备 |
| **延时和条件执行** | “半小时后关空调”“湿度低于40%再开加湿器” | 持久化调度、传感器状态和条件判断 |
| **家居状态汇总** | “现在还有哪些灯没关？” | 批量读取状态，区分关闭、离线、未知 |
| **主动播报** | “洗衣结束告诉我”“下载完成播报一下” | 接入设备事件或电脑任务状态 |
| **电脑控制增强** | “电脑音量调到20”“锁屏”“切换音频输出” | 增加明确、受限的系统操作 |
| **自有音频播放** | 播客、网络电台、NAS里的音频 | 可访问的音频地址、播放队列及机型适配 |
